Начиналось как личный органайзер

Материалы по клиентам разбросаны: часть в Excel, часть в переписке, часть в Aspro, часть в почте. Я собрал для себя одно место, где по каждому клиенту видно всё сразу. Потом подумал, что это может пригодиться коллегам, и сделал под каждую роль свой личный кабинет.

02 · Как это сделано

На чём написан сервис

Стандартный набор, на котором работает большая часть современных веб-сервисов. Ничего самодельного и ничего экзотического.

Claude Code
Разработка · Anthropic

Задача ставится словами, ИИ пишет код. Логику и специфику отдела задавал я — из наших регламентов и рабочих таблиц.

GitHub
Хранение кода

Каждое изменение записано: видно, что и когда менялось, любую правку можно откатить. Данные компании там не лежат.

Node.js · Next.js · React
Сам сервис · TypeScript

Открывается в браузере по адресу. Ставить ничего не нужно, работает и с телефона.

Prisma · SQLite
База данных

Клиенты, сделки, суммы, статусы. Лежит файлом на нашем сервере, рядом — папка с документами.

Ubuntu · nginx · pm2
Сервер

Отдельный арендованный сервер в России. nginx принимает запросы, pm2 держит сервис запущенным круглосуточно.

DeepSeek
ИИ внутри сервиса

Саммари по клиенту, разбор расшифровки встречи, поиск по базе знаний, раскладка входящих файлов.

Telegram
Уведомления

Вопрос руководителю, поручение, блокер и личное сообщение приходят в телеграм сразу.

Google-таблицы
Связь с текущими процессами

Заявки с сайта подтягиваются автоматически, показатели встреч уходят в таблицу отчётности.

05 · Маршрут

Что за что отвечает

Дальше перехожу в сам сервис и показываю вживую. Вот карта, чтобы не потеряться.

Каждый день

Сегодня
Цифры, статус дня, вопросы руководителю, поручения. Точка входа утром.
Задачи
Доска с приоритетами и файлами. Клиент подставляется в заголовок.
Дневник
Встречи и расшифровки. ИИ разбирает транскрипт и заполняет показатели.
Мессенджер
Чат отдела и личные сообщения, с привязкой к клиенту и сделке.

Клиент и сделка

Клиенты
Реквизиты, контакты, креативы и полная хронология по клиенту.
Сделки
Девять стадий, блокеры, сверка сумм, запрос юристу и на размещение.
Документы
Восемь подразделов, версии и несколько файлов в одной карточке.
База знаний
Правила, цены, техтребования. Отсюда же берёт данные ИИ-напарник.

Деньги и реклама

Оплаты
Календарь платежей по месяцам, сверка с суммой договора.
Календарь размещений
Что и когда выходит по клубам.
ОРД / маркировка
ЕРИД, креативы, акты по интернет-форматам.
Промокоды
Сроки, условия, взаиморасчёты.

Отдел

Обзор отдела
Только у руководителя: пульс по сотрудникам, воронка, блокеры.
Бюджет отдела
Сколько свободно, что ждёт согласования, куда уходят деньги.
Входящие с сайта
Обращения с формы. Ответственный — и задача заводится сама.
Передача дел
Календарь отпусков и передача клиентов замещающему.
