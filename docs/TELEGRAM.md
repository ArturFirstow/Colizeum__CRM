# Уведомления в Telegram

Чтобы вопрос руководителю, поручение и поднятый блокер не лежали в сервисе до
следующего входа, а приходили человеку сразу.

Настройка — 10 минут, один раз. Не настроено — сервис работает как раньше,
просто без уведомлений.

## Что приходит и кому

| Событие | Кто получает |
|---|---|
| Сотрудник задал вопрос руководителю | руководитель и админ |
| Руководитель ответил на вопрос | автор вопроса |
| Руководитель поставил поручение | сотрудник, которому поручили |
| По сделке подняли блокер | руководитель и админ |

Снятие блокера и обычные задачи не уведомляют — иначе бот превратится в шум.

---

## Шаг 1. Создаём бота

1. В Telegram найдите **@BotFather** и напишите ему `/newbot`.
2. Придумайте имя, например `Colizeum Agency`.
3. Придумайте логин — обязательно заканчивается на `bot`, например `colizeum_agency_bot`.
4. BotFather пришлёт **токен** вида `8123456789:AAF…`. Скопируйте его.

## Шаг 2. Прописываем токен на сервере

```bash
cd /root/Colizeum__CRM
nano .env
```

Добавьте в конец файла две строки (токен свой):

```
TELEGRAM_BOT_TOKEN="8123456789:AAF…"
APP_URL="https://colizeum-agensy.space"
```

`APP_URL` нужен, чтобы в сообщении была кликабельная ссылка на нужный раздел.

Сохранить: **Ctrl + O** → Enter → **Ctrl + X**.

## Шаг 3. Сотрудники пишут боту

Каждый сотрудник (включая вас) открывает бота в Telegram и отправляет `/start`.
Без этого Telegram не разрешает боту писать первым — это его защита от спама.

## Шаг 4. Привязываем чаты к сотрудникам

```bash
cd /root/Colizeum__CRM
npx tsx scripts/telegram-chats.ts
```

Команда покажет, кто написал боту и какой у него chat id, а ниже — список
сотрудников сервиса и у кого уведомления уже настроены:

```
Кто написал боту:

  chat id 123456789      Артур Фирстов (@artur)
  chat id 987654321      Марина Янюк

Сотрудники сервиса:

  a.firstov@colizeum.ru  Артур Фирстов  — уведомления не настроены
  m.yanyuk@colizeum.ru   Марина Янюк    — уведомления не настроены
```

Привязываем каждого — почта сотрудника и его chat id из верхнего списка:

```bash
npx tsx scripts/telegram-chats.ts a.firstov@colizeum.ru 123456789
npx tsx scripts/telegram-chats.ts m.yanyuk@colizeum.ru 987654321
```

То же самое можно сделать мышью: раздел **«Команда»** → сотрудник →
**«Изменить»** → поле «Telegram для уведомлений».

## Шаг 5. Перезапускаем и проверяем

```bash
pm2 restart colizeum --update-env
```

Проверка: зайдите в сервис под сотрудником, на «Сегодня» нажмите
**«Спросить руководителя»** и отправьте любой вопрос. Руководителю должно
прийти сообщение в Telegram со ссылкой на раздел.

---

## Если не приходит

| Что проверить | Как |
|---|---|
| Токен прописан | `grep TELEGRAM /root/Colizeum__CRM/.env` |
| Сервис перезапущен после правки `.env` | `pm2 restart colizeum --update-env` |
| Сотрудник написал боту `/start` | без этого Telegram блокирует отправку |
| Chat id привязан | `npx tsx scripts/telegram-chats.ts` — в списке сотрудников должно быть «→ чат …» |

Сервис намеренно не падает, если Telegram недоступен: запись сохранится в любом
случае, потеряется только уведомление.

> **Про доступ из России.** `api.telegram.org` с российских серверов обычно
> доступен. Если бот молчит, а всё остальное настроено — проверьте прямо с
> сервера: `curl -s https://api.telegram.org/bot<ТОКЕН>/getMe`. Ответ должен
> содержать `"ok":true`.
