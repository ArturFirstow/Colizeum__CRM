# Colizeum Workspace

Приватный внутренний сервис менеджера рекламных проектов сети киберклубов **COLIZEUM**. Объединяет то, что раньше было разбросано по Aspro, таблицам, чатам и почте:

- 🗂️ **CRM** — рекламодатели, агентства, сделки и их движение по стадиям;
- 📄 **Хранилище документов** — договоры, приложения, УПД, счета и т.д. с папками по контрагенту/типу и **версионированием**;
- 📚 **База знаний** — форматы, цены, ОРД, промокоды, люди, кейсы — с полнотекстовым поиском;
- ✎ **Рабочий журнал** — EOD-сводки и транскрипты встреч.

Собран по [техническому блупринту](docs/Colizeum_Workspace_БЛУПРИНТ_v2.md) (v2).

## Скриншоты

Дашборд «Сегодня» · канбан сделок по стадиям · хранилище документов с версиями · база знаний · финансовая цепочка. Тёмная тема, фирменные чёрный + жёлтый, мотив «ХО».

## Стек

| Слой | Технология |
| --- | --- |
| Фреймворк | Next.js 15 (App Router) + TypeScript |
| UI | React 19 + Tailwind CSS |
| БД / ORM | Prisma + SQLite (dev) → PostgreSQL (prod) |
| Auth | Cookie-сессия (JWT `jose`) + bcrypt, 2 аккаунта |
| Файлы | Абстракция `StorageProvider`: локальный диск (dev) → S3-совместимое (prod) |
| Валидация | Zod на границах API |
| AI (v2) | Anthropic SDK (только сервер) |

## Быстрый старт

```bash
npm install
cp .env.example .env
npm run setup      # prisma generate + db push + сид демо-данных
npm run dev        # → http://localhost:3000
```

| Owner | `owner@colizeum.ru` | `colizeum` |
| Manager | `manager@colizeum.ru` | `colizeum` |

## Что реализовано

**Фаза 0 + MVP + значительная часть v1:**

- Приватная авторизация на 2 аккаунта, защита роутов, редирект гостей.
- **Рекламодатели (CRM):** карточки (юрлицо, ИНН/КПП/ОГРН, тип-тег, цели), контакты, поиск, фильтр по типу.
- **Документы:** дерево «рекламодатель → тип → документ → версии», загрузка, **версионирование** (новая загрузка = новая версия, старые остаются и скачиваются), дедуп по SHA-256, скачивание через backend.
- **Сделки:** канбан (9 групп) + список, 11 нормализованных стадий, **инварианты стадий** с предупреждениями к подтверждению, карточка сделки с блокерами/решениями/следующим шагом.
- **Финансы:** цепочка Счёт → Платёж → УПД → Отчёт → Акт сверки; контроль актуального р/с (⚠️).
- **Медиапланы, ОРД/маркировка, промокоды** — реестры и добавление в карточке сделки.
- **Задачи:** доска по статусам, виды, делегирование, дедлайны.
- **Дашборд «Сегодня»:** решения, которые ждут; задачи; блокеры; зависшие сделки; журнал.
- **База знаний:** статьи по категориям, поиск, рендер Markdown с таблицами, редактирование.
- **Журнал:** ручная запись EOD/транскриптов (AI-разбор — v2).

**Заложено в схему/архитектуру, но пока не реализовано (v2/v3):** AI-функции (разбор входящих, генерация КП/ОРД-ТЗ/отчётов, разбор EOD-сводок), RBAC + аудит-лог, фоновые задачи, S3-хранилище, прод-деплой (PostgreSQL + HTTPS + бэкапы).

## Структура

```
prisma/            schema.prisma (все сущности) + seed.ts (сид из баз знаний)
src/
  app/
    (app)/         страницы модулей (server components) под layout с сайдбаром
    api/           REST-роуты (мутации, Zod, единый формат ошибки)
    login/         страница входа
  components/      клиентские островки (формы, модалки, канбан, дерево документов)
  lib/             enums, prisma, auth, storage, validation, services, format, org, markdown
docs/              блупринт v2
```

## Переменные окружения

См. `.env.example`. Секреты (`AUTH_SECRET`, ключи хранилища, `ANTHROPIC_API_KEY`) — только в окружении, не коммитятся.
