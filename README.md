# Colizeum Agency

Внутренний сервис менеджера рекламных проектов сети киберклубов **COLIZEUM**. Объединяет то, что раньше было разбросано по таблицам, чатам и почте:

- 🗂️ **CRM** — контрагенты (рекламодатели/агентства с клиентами), сделки по стадиям;
- 📄 **Документы** — иерархия по контрагенту (Договоры / Приложения / ДС / Счета и УПД / Медиапланы / Креативы / Отчёты) с **версионированием**;
- ▦ **Календарь размещений** — Gantt по слотам и неделям (как рабочая таблица);
- ₽ **Финансы** — помесячный календарь платежей (кто/сколько/когда);
- ❖ **ОРД** — реестр ЕРИД с креативами, PDF-актами и флагом срочности;
- % **Промокоды** — карточки по рекламодателям;
- ◆ **«Сегодня»** — решения/блокеры/задачи + ежедневные статусы → **недельный отчёт**;
- ◈ **База знаний** — с блоком «Материалы для клиента».

Дизайн — по брендбуку COLIZEUM 2025 (жёлтый #FCDF3B, графит, знак-маска «ХО»).

## Стек

| Слой | Технология |
| --- | --- |
| Фреймворк | Next.js 15 (App Router) + TypeScript |
| UI | React 19 + Tailwind CSS |
| БД / ORM | Prisma + SQLite (dev) → PostgreSQL (prod) |
| Auth | Cookie-сессия (JWT `jose`) + bcrypt, 2 аккаунта |
| Файлы | `StorageProvider`: локальный диск (dev) → S3-совместимое (prod) |
| Валидация | Zod на границах API |
| AI (план) | Anthropic SDK (только сервер) |

```bash

cp .env.example .env
npm run setup      # prisma generate + db push + сид демо-данных
```

## Модули

- **Сегодня** — метрики, «решения, которые ждут», задачи, блокеры, зависшие сделки, журнал; панель «Статус дня по проектам» и генератор недельного отчёта (превью / копировать / скачать `.md`).
- **Сделки** — канбан (9 групп) + список, 11 стадий, инварианты переходов с подтверждением. Этап сделки — единый источник статуса для задач и карточек контрагентов.
- **Задачи** — доска по статусам, виды (юрист/дизайн/менеджер/бухгалтерия/ОРД), делегирование, дедлайны.
- **Рекламодатели** — чистые карточки (только суть + флаг ⚠️), внутри: реквизиты (редактируемые), контакты, сделки, документы; у агентств — список клиентов (добавить/удалить).
- **Документы** — 8 фиксированных подразделов у каждого контрагента (показываются даже пустыми), версионирование (новая загрузка = новая версия, дедуп по SHA-256), скачивание любой версии.
- **Календарь размещений** — строки = слоты/форматы, колонки = недели; полосы-бренды с цветом по статусу (подписан / на подписании / ожидание); бронирование и удаление.
- **Финансы** — итоги выставлено/оплачено/остаток, помесячный календарь плановых платежей с ручным вводом, контроль расчётных счетов (⚠️).
- **ОРД / маркировка** — добавление/удаление ЕРИД, роль (Агентство/Клиент), даты размещения, загрузка картинки креатива и PDF-акта, флаг «срочно».
- **Промокоды** — карточки по рекламодателям: номиналы, количество, сроки, коммерческие условия, взаиморасчёт.
- **База знаний** — категории + поиск + Markdown-таблицы; блок «📮 Материалы для клиента» (медиакит, шаблоны МП, учредительные, исследование аудитории, техтребования, рамка договора, карточка компании).
- **Журнал** — EOD-сводки/транскрипты с ручной маршрутизацией.

Во всех сущностях — **удаление с подтверждением**.

## Структура

```
prisma/            schema.prisma (все сущности + связи) + seed.ts (демо-данные)
src/
  app/
    (app)/         страницы модулей (server components) под layout с сайдбаром
    api/           REST-роуты (Zod, единый формат ошибок)
    login/         вход
  components/      клиентские островки (формы, модалки, канбан, календари)
  lib/             enums, prisma, auth, storage, validation, services, org, markdown
docs/              блупринт v2
```

AI-функции (разбор документов, генерация КП/ОРД-ТЗ/отчётов, разбор EOD), RBAC + аудит-лог, фоновые задачи, S3 + прод-деплой (PostgreSQL, HTTPS, бэкапы). Схема БД и архитектура под них заложены.
