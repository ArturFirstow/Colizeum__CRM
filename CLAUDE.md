# Colizeum Workspace — проект

Приватный веб-сервис менеджера рекламных проектов COLIZEUM: **CRM + база знаний + хранилище документов с версионированием + рабочий журнал**.

Полное ТЗ — в `docs/Colizeum_Workspace_БЛУПРИНТ_v2.md`. Читай его в начале сессии, если работаешь над доменной логикой.

## Про пользователя

Пользователь — не программист. Объясняй просто, по-русски. Работай маленькими шагами. Не создавай/не меняй файлы без подтверждения, если задача неочевидна.

## Текущее состояние

Реализованы **Фаза 0 (каркас) + MVP (Рекламодатели + Документы с версиями) + значительная часть v1** (сделки/стадии/инварианты, задачи, дашборд, база знаний, финансы, ОРД, промокоды, журнал).

**НЕ сделано (осознанно, это v2/v3):** AI-функции (разбор документов, генерация КП/ОРД-ТЗ/отчётов, разбор EOD), RBAC + аудит-лог, фоновые задачи, S3-хранилище и прод-деплой. Схема БД и роуты под них уже заложены.

## Как запустить

```bash
npm install
cp .env.example .env      # при необходимости поправить секреты
npm run setup             # prisma generate + db push + seed
npm run dev               # http://localhost:3000
```

Демо-аккаунты (из сида): `owner@colizeum.ru` и `manager@colizeum.ru`, пароль `colizeum`.

Полезное: `npm run db:seed` (пересев), `npm run db:reset` (сброс миграций), `npm run build`.

## Архитектура (детали — раздел 4 блупринта)

- **Монолит, один репозиторий:** Next.js 15 (App Router) + TypeScript + Tailwind.
- **БД/ORM:** Prisma + SQLite (dev) → PostgreSQL (prod). Схема — `prisma/schema.prisma`, заведены ВСЕ сущности сразу.
- **Перечисления:** SQLite не поддерживает native enum → храним String, единый источник значений `src/lib/enums.ts`, валидация Zod (`src/lib/validation.ts`).
- **Файлы:** абстракция `StorageProvider` (`src/lib/storage/`), в dev — локальный диск (`./storage`). В БД только метаданные версий (ключ, имя, размер, sha256, номер версии, кто загрузил, changeNote).
- **Auth:** приватный сервис на 2 аккаунта. Cookie-сессия (JWT `jose`, httpOnly), пароли bcrypt. `src/lib/auth.ts`. Роли Owner/Manager заложены полем, RBAC — v2.
- **Слои:** UI (server components читают Prisma напрямую; клиентские островки для мутаций) → API routes (`src/app/api/**`, Zod-валидация, единый формат ошибки) → сервисы (`src/lib/services/**`) → Prisma.
- **AI (v2):** `@anthropic-ai/sdk`, только с сервера, ключ в env. AI формирует *предложение*, пользователь подтверждает, потом пишем в БД.

## Незыблемые правила домена (инварианты, раздел 7 блупринта)

Проверяются на бэкенде (`src/lib/services/deal-stage.ts`), возвращаются как предупреждения к подтверждению:

- Приложения Т-Банка согласуются строго по очереди — нельзя перепрыгивать этапы.
- Правки после подписания, если клиент не может править тело договора → оформляем **ДС** (кейс Алабуга).
- Платежи по клубу на ИП нельзя через счёт УК — нужен отдельный счёт под ИП клуба.
- Размещение (стадия 9) стартует только после зафиксированной предоплаты.
- НДС по дате документа: 2025 → 20 %, 2026 → 22 % (`vatRateForDate`).

## Точки на выверку (⚠️, раздел 16)

В сиде и UI помечены ⚠️: актуальный р/с (основной …48430 vs Самокат-fest …55743), КПП МТС (770901001/997750001), сумма Алабуга (9 955 200 vs 9 555 200), канон стадий (11 vs 9), две «Миланы» в директории людей.

## Стиль

Фирменный: **чёрный + жёлтый, мотив «ХО»**. Тёмная тема. Токены цветов стадий/статусов — `src/lib/ui-tokens.ts`, компоненты — `src/components/`.

## Карта кода

- `src/lib/` — enums, prisma, auth, storage, validation, api-хелперы, format, org (реквизиты УК), markdown, services.
- `src/app/(app)/` — страницы модулей (server components) под общим layout с сайдбаром.
- `src/app/api/` — REST-роуты (мутации).
- `src/components/` — клиентские компоненты (формы, модалки, канбан, дерево документов).
- `prisma/seed.ts` — сид-данные из баз знаний.
