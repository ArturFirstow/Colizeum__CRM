# Рекламный ролик: подвеска-брелок «you are the key» (Poison Drop Lab)

Вертикальный ролик 1080×1920, 20 секунд, 30 кадров/с. Готовый файл —
`out/poisondrop-you-are-the-key.mp4`. Формат подходит для Reels, Shorts,
VK Клипов и сторис.

## Из чего состоит ролик

| Время | Что происходит |
|---|---|
| 0–4 с | Плавный вход из чёрного: разгорается свет, изделие выплывает из размытия, сверху — бренд, снизу — обещание «Ключ, который носят на себе» |
| 4–10 с | Презентация: название товара и три причины забрать |
| 10–14 с | Смысл: крупная строка «you are the key» поверх приглушённого изделия |
| 14–20 с | Призыв: название, цена, кнопка, адрес сайта — и затухание в чёрный |

Изделие живёт весь ролик одним планом: парит, по металлу бежит блик,
на сцене со смыслом уходит в мягкий фон и возвращается к финалу.

## Что нужно заменить перед публикацией

Всё правится в `src/Root.tsx`, в блоке `defaultProps` — или прямо в
Remotion Studio, поля подписаны по-русски.

- **`photoSrc`** — сейчас пусто, поэтому рисуется векторная подвеска.
  Положите фотографию товара в `public/` (например `pendant.png`, лучше
  PNG с прозрачным фоном) и впишите `photoSrc: "pendant.png"`. Можно
  указать и прямую ссылку на картинку.
- **`price`** — сейчас пусто, блок цены скрыт. Впишите строкой:
  `price: "4 900 ₽"`.
- **`bullets`** — три строки-выгоды. Заменить на реальные характеристики
  (материал, размер, покрытие), когда они будут известны.
- **`productName`**, **`ctaLabel`**, **`site`**, **`brand`** — текст.

## Как посмотреть и пересобрать

```bash
npm install
npx remotion studio        # предпросмотр и правка мышкой
npx remotion render PoisonDropPromo out/poisondrop-you-are-the-key.mp4 --crf=17
```

Шрифты (Playfair Display и Inter) лежат в `public/fonts` — интернет при
рендере не нужен.

## Чего в ролике нет

- **Музыки.** Дорожка не добавлена: нужен трек с правами на рекламное
  использование. Добавляется одной строкой `<Audio src={staticFile("music.mp3")} />`
  в `src/PoisonDropPromo.tsx`.
- **Реальных фотографий и характеристик товара** — сайт poisondrop.ru
  недоступен из среды, где собирался ролик.
