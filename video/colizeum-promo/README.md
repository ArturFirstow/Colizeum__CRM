# Презентационный ролик сервиса Colizeum Agency

Горизонтальный ролик 1920×1080, 32 секунды, со звуком. Готовый файл —
`out/colizeum-agency-promo.mp4`.

## Что внутри

| Время | Что на экране |
|---|---|
| 0–4 с | Заставка: знак «ХО», COLIZEUM AGENCY, «Рабочий сервис отдела рекламы» |
| 4–8 с | Слова в такт музыке: Клиенты. Сделки. Документы. Деньги. → «Один сервис вместо десяти таблиц» |
| 8–12 с | **Сегодня** — день на одном экране |
| 12–16 с | **Оплаты** — календарь платежей |
| 16–20 с | **Календарь размещений** — слоты и недели |
| 20–24 с | **Клиенты и сделки** — девять стадий |
| 24–26 с | **Напарник ИИ** |
| 26–28 с | Быстрая нарезка по удару: ОРД, Промокоды, Мессенджер, Деньги отдела |
| 28–32 с | Финал: «Весь отдел — в одном окне» и адрес сервиса |

Монтаж привязан к музыке: 120 ударов в минуту, то есть удар = 15 кадров,
такт = 60 кадров. Все склейки попадают на начало такта, а в конце темп
нарезки удваивается — отсюда ощущение разгона.

## Экраны

`public/shots/*.png` — настоящие скриншоты сервиса, снятые с рабочей
сборки на демо-данных (сид). Если экраны изменятся, переснимите их и
положите файлы с теми же именами.

⚠️ На скриншотах видны демо-данные из `prisma/seed.ts` (Алабуга, МТС,
Т-Банк). Перед показом наружу проверьте, что там нет ничего лишнего.

## Музыка

Трек написан скриптом `scripts/music.mjs` — синтез с нуля, никаких
сторонних сэмплов, поэтому вопросов с лицензией нет. 120 BPM, ля минор,
16 тактов: тихое вступление → вход бита → «дроп» на 8-й секунде → плотная
часть → финальный удар и затухание.

```bash
node scripts/music.mjs                 # получится public/music.wav
npx remotion ffmpeg -i public/music.wav -codec:a libmp3lame -b:a 192k public/music.mp3
```

В репозитории лежит только `public/music.mp3` (WAV весит 6 МБ и собирается
скриптом за секунду).

## Как посмотреть и пересобрать

```bash
npm install
npx remotion studio         # предпросмотр, тексты правятся мышкой
npx remotion render ColizeumPromo out/colizeum-agency-promo.mp4 --crf=18
```

Шрифты брендбука (Oswald, Manrope) лежат в `public/fonts` — интернет при
рендере не нужен.

## Что можно улучшить

- Вертикальная версия 1080×1920 для сторис — делается копией композиции

- Закадровый голос: сейчас ролик держится на музыке и подписях.
