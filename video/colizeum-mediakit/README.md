# Продающий ролик по рекламным возможностям COLIZEUM

Горизонтальный ролик 1920×1080, **1 минута 34 секунды**, со звуком. Готовый
файл — `out/colizeum-mediakit-final.mp4`. Сделан по медиакиту COLIZEUM Agency
(версия 2026.3) и в его же айдентике: чёрный фон, модульная сетка,
ультражирные заголовки, жёлтый акцент, правый жёлтый рельс с номером
раздела.

## Сценарий

| Время | Раздел | Что говорим |
|---|---|---|
| 0–4 с | Крючок | 1 600 000 геймеров в месяц приходят в клубы |
| 4–8 с | Сеть | Самая крупная сеть компьютерных клубов в мире, №1 площадка офлайн-коммуникации с геймерами, награды |
| 8–16 с | Масштаб | 570 арен · 220 городов · 18 стран · 20 000 ПК · 1 800 ТВ · 3 500 турниров |
| 16–20 с | Аудитория | 450 000 уникальных гостей, 3,5 млн часов сессий, 80 млн знают бренд |
| 20–24 с | Почему работает | **50,8 % покупали товары брендов, чью рекламу видели в клубе**, NPS 73 %, CTR 2–6 % |
| 24–28 с | Заход в экран | Камера идёт по залу клуба, монитор с рекламой выходит вперёд и заполняет кадр |
| 28–34 с | **Формат 01** | Баннеры на свободных ПК и ТВ — 20 000 ПК и 1 800 ТВ |
| 34–40 с | **Формат 02** | Баннер в личном кабинете — 2 слота, 2 показа в минуту |
| 40–46 с | **Формат 03** | Баннер на рабочем столе игрока — CTR 2–6 % |
| 46–52 с | Ещё каналы | Браузер, приложение, соцсети |
| 52–60 с | Турниры | 3 500 турниров, три уровня спонсорства, арена Шелепиха |
| 60–66 с | Клиенты | Стена из 16 реальных клиентских креативов |
| 66–86 с | Кейсы | «Горячая штучка», Уралсиб, Thunderobot, ASUS ROG — по 5 секунд на кейс |
| 86–94 с | Контакты | Соберём кампанию под задачу, телеграм и сайт |

Драматургия продающая: сначала масштаб аудитории, потом доказательство,
что реклама окупается, затем инструменты, затем чужие результаты, и только
в конце — призыв.

## Картинки

`public/img/` — 33 изображения, вынутые прямо из PDF медиакита
(`pymupdf`, встроенные JPEG в исходном разрешении):

- `club-*.jpg` — интерьеры клубов и арены, идут фонами под текстом;
- `fmt-*.jpg` — макеты по каждому формату (монитор с рекламой OZON,
  личный кабинет, виджет, браузер, приложение, пост в соцсетях);
- `ad-01…ad-16.jpg` — креативы реальных рекламодателей для стены клиентов;
- `case-*.jpg` — фоны под кейсы.

Отбирались автоматически по яркости и контрасту: в PDF рядом с макетами
лежат чёрные маски-подложки того же размера, на глаз их не отличить.

## Приёмы монтажа

- **Три главных формата — по отдельному экрану** (`src/scenes/FormatBig.tsx`):
  крупный макет справа, слева номер в жёлтой плашке, название, главная
  цифра жёлтым блоком и три пункта. По 6 секунд на формат, чтобы успевать
  читать. Остальные три канала — одним экраном (`FormatsRest.tsx`).
- **Заход в экран** (`src/scenes/PushIn.tsx`) — фон зала наезжает, монитор
  вырастает с 0,34 до 2,5 и «съедает» кадр; стык с блоком форматов не виден.
- **Жёлтые шторки** (`src/components/Sweep.tsx`) — на восьми главных
  склейках через кадр проносится жёлтая панель, за ней чёрная.
- **Вспышки** на музыкальных ударах (кадры 240, 840, 1320, 1800).
- **Набегающие цифры** и вытирание заголовков слева направо — из вёрстки
  самого медиакита, только в движении.

## Откуда цифры

Все до единой — из медиакита. Ничего не додумано. Если цифры в медиаките
обновятся, править нужно в этих файлах:

- `src/scenes/Scale.tsx` — масштаб сети
- `src/scenes/Audience.tsx` — аудитория и доказательство эффективности
- `src/scenes/FormatBig.tsx` + вызовы в `src/MediaPromo.tsx` — три главных формата
- `src/scenes/FormatsRest.tsx` — массив `REST`, остальные три канала
- `src/scenes/Tournaments.tsx` — массив `LEVELS` и арена
- `src/MediaPromo.tsx` — четыре кейса прямо в разметке
- `src/scenes/Cta.tsx` — контакты

## Музыка

Трек написан скриптом `scripts/music.mjs` — синтез с нуля, без сторонних
сэмплов, вопросов с лицензией нет. 120 BPM, 47 тактов: вступление →
вход бита → основная часть → передышка на разделе «Форматы» → разгон →
пик на турнирах и кейсах → финал.

```bash
node scripts/music.mjs
npx remotion ffmpeg -i public/music.wav -codec:a libmp3lame -b:a 192k public/music.mp3
```

Монтаж привязан к музыке: удар = 15 кадров, такт = 60 кадров, все склейки
падают на начало такта, жёлтые вспышки — на музыкальных ударах.

## Как посмотреть и пересобрать

```bash
npm install
npx remotion studio
npx remotion render ColizeumMediaPromo out/colizeum-agency-mediakit.mp4 --crf=18
```

Шрифты (Oswald, Manrope) лежат в `public/fonts` — интернет при рендере не нужен.

## Чего в ролике нет

- **Фотографий и скриншотов рекламных мест.** В медиаките они есть
  (монитор с баннером OZON, интерфейс личного кабинета, фото арены), но
  вытащить картинки из PDF в приемлемом качестве не удалось. С реальными
  фото ролик станет заметно живее — достаточно положить их в `public/`.
- **Вертикальной версии** 1080×1920 для сторис.
- **Закадрового голоса** — ролик держится на музыке и типографике.
